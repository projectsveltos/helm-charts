# Third-Party License Notices

This chart deploys the `dashboard` (frontend, JavaScript/npm) and `ui-backend` (API server, Go)
images as one bundle, distributed separately from the main Sveltos chart (see
`../../THIRD_PARTY_LICENSES.md` for that bundle's notices). This document lists every
third-party license found in both images' actual dependency trees.

`ui-backend`'s Go dependencies were generated by scanning its build target with
[`google/go-licenses`](https://github.com/google/go-licenses):

```bash
go install github.com/google/go-licenses/v2@latest
go-licenses report ./cmd/...   # run from the ui-backend repo
```

`dashboard`'s JavaScript dependencies were generated with pnpm's built-in license checker,
restricted to production dependencies (build-only tooling like bundlers/linters never ships in
the served bundle, so it's excluded the same way dev-only Go tooling is excluded from the Go
side):

```bash
pnpm install --frozen-lockfile
pnpm licenses list --prod --json   # run from the dashboard repo
```

First-party `github.com/projectsveltos/*` Go packages are excluded (Sveltos's own code, not
third-party).

## Regenerating this document

Run `helm-charts/scripts/update-third-party-licenses.sh` before cutting a release, then review
the diff here. Don't hand-edit the tables below.
